Features

What this firmware gives you on a K-Touch / PandaTouch:

  • U1 remote mirror Fullscreen live view of the Snapmaker U1 panel over Wi-Fi (same /screen/ protocol as the browser client).
  • Touch forwarding Taps and drags on the K-Touch are sent to the printer so you can drive the U1 UI remotely.
  • Multi-printer manager Save up to 8 printers in a 2x4 grid - each with a name and IP. Tap to switch; the old session is cleared before reconnecting.
  • On-device Wi-Fi setup Scan networks, connect, and store credentials in NVS. No serial console required for day-to-day use.
  • Named printer profiles Give each U1 a label (e.g. Shop U1) tied to its IP on the Printer Setup page.
  • Boots into the mirror After Wi-Fi and a printer are configured, the device opens the remote panel automatically - gear menu for Wi-Fi, Printer Manager, and About.
  • Auth-aware Remote Screen Works with optional Moonraker / nginx auth (username/password or API key) when your U1 is locked down.
  • Browser flashing Install from Chrome or Edge over USB with Web Serial - no PlatformIO needed for end users.

Requires a Snapmaker U1 running Paxx Extended Firmware with Remote Screen enabled.

Requirements

  1. Use Google Chrome or Microsoft Edge on desktop (Web Serial API).
  2. This page must be served over HTTPS (GitHub Pages works).
  3. Connect the K-Touch / PandaTouch with a USB-C data cable to your PC.
  4. If the device is not detected, hold BOOT, tap RESET, release BOOT, then connect.

Initializing…

Uses 115200 baud and uncompressed writes for CH340 USB bridges. Takes ~2-3 minutes - keep the cable still.

Disclaimer: PaxxTouch is not responsible for damage to your device. Flashing third-party firmware may void your manufacturer warranty. Proceed at your own risk.

After flashing

  1. Disconnect USB (or tap Reset if the screen stays blank).
  2. Tap the gear icon (top-right) → WiFi Setup and connect to your LAN.
  3. Gear → Printer Manager - add a printer (name + IP), or edit the active slot. Up to 8 printers in a 2x4 grid.
  4. On the U1: enable Remote Screen in firmware-config and reboot if prompted.
  5. The device opens a fullscreen mirror of the U1 panel. Switch printers anytime from Printer Manager.
